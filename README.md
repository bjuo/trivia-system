# מערכת טריוויה טלפונית

## התקנה ב-Render
1. חבר את הריפו הזה ל-Render כ-Web Service
2. Build Command: npm install
3. Start Command: npm start
4. לאחר הפריסה, קבל את כתובת ה-URL

## עמודים
- /admin.html - ניהול משחקים ושאלות
- /control.html?code=XXXX - שליטה למנחה
- /display.html?code=XXXX - מסך תצוגה
- /yemot - קצה API לימות המשיח (לשים ב-api_link)
